## 再打开一次

线上部署如果还在，直接打开即可。本地：

```bash
pnpm install
pnpm dev
```

地图需要 Mapbox 公钥。在项目根目录建 `.env`（已被 git 忽略），写一行：

```
MAPBOX=pk.你的公钥
```

变量名就是 `MAPBOX`。服务端在 `app/page.tsx` 读它，再传给页面。没有这行，或 token 失效时，地图位置会改成坐标列表，高德搜索链接仍然可用。公钥请在 Mapbox 后台限制到自己的域名。

部署用过 Vercel，安装时是 `pnpm install --frozen-lockfile`。改依赖要让 `pnpm-lock.yaml` 和 `package.json` 一致。仓库里同时有 `package-lock.json`。

## 仓库里是什么

- `lib/content.ts`：五天文案、票价、清单、照片署名
- `lib/routes.json`：每天的驾车折线，坐标是 WGS84（OSRM）
- `lib/gcj02.ts`：只在打开高德时把坐标从 WGS84 转到 GCJ-02，页内地图不转
- `components/`：总览、单日、Mapbox 地图
- `public/photos/`：认景、认菜的图，不是这次路上拍的

行前记下的票价：南华寺 15 元，高椅岭 92 元，东江湖观湖线 78.8 元，仰天湖直通车 169 元（含门票）。天气是出发前的预报。这些数字留在文案里，只说明当时怎么排的。
